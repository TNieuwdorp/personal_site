In this marimo-hosted livestream I walk through the first technical preview of Polars Cloud, showing how Polars can scale beyond a single machine.

Topics covered:

- **Polars Cloud overview:** What it is and how it extends the Polars API for distributed workloads.
- **Remote execution:** Running a Polars query on a cluster without changing your local code.
- **Query Profiler:** The new tool for understanding where time is spent in a distributed query plan.
- **Multi-node clusters:** How data is shuffled and balanced across nodes during execution.
- **Live demo:** End-to-end walkthrough of setting up and running a job on Polars Cloud.
